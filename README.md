# Intermodular 03 — Equip 4

Projecte web educatiu en català sobre **quatre sèries de televisió**, desenvolupat amb **HTML5 i CSS3**. El lloc inclou una pàgina principal amb accés a les quatre fitxes, que contenen una imatge, una sinopsi, un enllaç a IMDb i estils CSS personalitzats.

### Treball col·laboratiu: forks i pull requests

1. Cada integrant crea un **fork** del repositori de l'equip.
2. Treballa sobre la seva còpia i registra els canvis amb **commits**.
3. Envia els canvis mitjançant una **pull request** cap a la branca principal `master` del repositori original.
4. Es revisa la proposta i, si és correcta, es fusiona (**merge**).
5. S'actualitzen la issue corresponent i el seu estat al Kanban.

Alguns exemples de contribucions integrades són la [PR #12](https://github.com/santimartinezcordoba-prog/intermodular03equip4/pull/12) i la [PR #15](https://github.com/santimartinezcordoba-prog/intermodular03equip4/pull/15).

## Com executar el projecte

1. Descarregueu o cloneu aquest repositori.
2. Obriu `index.html` en un navegador o amb **Live Server** a Visual Studio Code.
3. Navegueu entre la pàgina principal i les fitxes de les quatre sèries.

No cal instal·lar dependències ni compilar cap aplicació.

## Recursos

Les pàgines fan servir imatges emmagatzemades a `img/`, estils propis a `css/` i enllaços cap a les fitxes de les sèries a IMDb. Cal comprovar que es disposa dels permisos necessaris per utilitzar les imatges.
